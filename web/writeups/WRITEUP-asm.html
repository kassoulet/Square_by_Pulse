SQUARE - asm notes (so far)

Work in progress: the effects have not been analysed yet. What the first pass found:

  • Callback registry as a tick scheduler (0x1c9c5 / 0x1ca49 / 0x1ca79 / 0x1cab2): eight slots {fn, last-tick stamp, arg}; the 60 Hz MIDAS ISR callback runs the slots, and 0x1cab2 loops elapsed ticks times so animations are frame-rate independent (returns dt). Tiny, branchy, all in registers.
  • Lazy PAK decoding: the file struct hands out compressed bytes; the decoder is a bit-stream state machine (0x1d92e init, 0x1d9e3 read n bits with a rotating 0x80 mask) that is only run by the read function 0x1d97a. Dumping the buffer after "load" gives compressed noise, which is how we found it.
  • Inner loop of the first scene (0x29ea8..0x29ee1): dst[i] = lut[(((a[i]<<2)+b[i])<<8) + c[i]] over 320x480 samples with three byte streams, one table lookup per pixel, row pointer advance with a pseudo random offset (call 0x3b6cb & 0x1ff).

Static recompilation of the scenes (session 6)

Instead of porting each scene by hand, re/x86js.py turns the original machine code into JavaScript: an objdump listing of the PMODE/W flat image becomes one JS function per x86 function (a for(;;) switch(pc) per function), the registers and flags are module variables, memory is a flat 128 MB DataView and the x87 stack lives in web/js/x86rt.mjs. The x87 control word of this demo selects 24-bit precision, so every add/sub/mul/div/sqrt is rounded to float32 (found earlier from the blur argument 0.9199999571); fist rounds to nearest even, the chop-frndint helper truncates. Hardware and libc are replaced by a few natives: the present routines grab the 320x200 / 320x240 / 320x480 index buffer and then play the harness's two 60 Hz ISR ticks (the type-1 callbacks of the registry, among them the palette crossfade 0x260d5 that rewrites all 768 DAC values every tick), the poll 0x1ca79(0) hands out the song position and runs the type-0 callbacks once per elapsed tick, files are read from the PAK, malloc is a bump allocator. The scene runs on a snapshot that holds only the 0.35-0.39 MB of memory it reads (found by zeroing chunks of the dump until the output changed). The recompiled opening scene (0x29a81) and the dune scene (0x338a5) reproduce the Unicorn run bit for bit on 749 of 752 flips (see re/NOTES.md Session 6 for the three exceptions).
