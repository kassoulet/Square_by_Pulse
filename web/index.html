Pulse (pLsE), 1998 - JavaScript port: work in progress (music + 3 scenes)
0:00 / 4:23

Three scenes are shown: the opening portrait (0:00-0:21) and the dune texture (3:28-3:32) run the original's own code, statically recompiled to JS and run frame by frame (about 50-90 ms per frame, so the picture can lag the music); the last scene, people (from 3:38), is a hand port, partly approximated. The other scenes are not ported yet (see the write-ups and re/NOTES.md). The 320x200 frame is shown 4:3 as the original's pixels are not square. The music is the original SQUADEMO.XM through libopenmpt.
